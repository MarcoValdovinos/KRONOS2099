# Chairs IETF aplicado a KRONOS2099

Fuente: https://github.com/ietf/chairs.ietf.org - sitio oficial para chairs de Working Groups.

## Qué aprendimos

1. En IETF no se vota, se construye consenso.
   - Si hay consenso rough, se avanza aunque no sea unánime.
   - KRONOS2099 usa lo mismo: 51% Humano decide, 49% IA ordena, comunidad opina.

2. Reglas de escritura IETF que ya aplicamos:
   - Decir Internet-Drafts o I-Ds, nunca drafts
   - Encabezados en orden H1, H2, H3
   - Escribir en segunda persona, hablando directo
   - Enlaces internos con título completo

3. Flujo GitHub:
   - Cambios por pull request
   - Sincronización cada 5 minutos entre repo y sitio
   - Igual que KRONOS2099 con 【entity-GitHub¦canonical_name=GitHub】 Pages

4. Para presentar KRONOS2099:
   - Paso 1: Hablar con chairs de grupos relacionados, no directo a IESG
   - Grupos posibles: IoT, Automated Network Management, RDAP, IDN
   - Paso 2: Llevar draft-00 con checklist de chair
   - Paso 3: Pedir slot en Hackathon IETF 128 para demo de verificador
